# Neglected Crops in a CRISPR World

Janne Bibbe & Jonathan Arentoft

2025-2026

- cleaning and harmonizing orphan crop datasets from AOCC, FAO 2024 and VASC
- comparison to well-researched plants from  [Marks et al 2023](https://www.pnas.org/doi/10.1073/pnas.2217564120), with [data in Dryad](https://doi.org/10.5061/dryad.pg4f4qrtb)
- integrating metadata on genome/protocol availability and publication counts
- visualizing crop diversity and metadata patterns

Run `data_prep.R` first, then run `figure_combined.R` to visualize the results.
